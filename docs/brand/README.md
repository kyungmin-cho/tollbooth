# Tollbooth brand

Owner-selected option 01 (raised barrier), supplied 2026-10-18. The four original PNG files are preserved here unchanged as requested; only option 01 is used in the application.

`public/tollbooth-mark.svg` is a faithful manual vector redraw with one even-odd path: the raised arm, pedestal, circular pivot cutout and rectangular arm cutout. Fill is `#1546E6`; the background and cutouts are transparent. No raster image is embedded. The header lockup uses this mark and real “Tollbooth” text in the app font. The original generated horizontal lockup is reference only.

`public/favicon.svg` uses the same vector; the 32px and 180px PNGs were rendered from it with Chromium on transparent backgrounds. No CSS letter placeholder remains.
